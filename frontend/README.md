# Frontend - Papelaria Comissões

React + TypeScript (Vite). Consome a API Django em `../backend`.

Instruções completas de instalação, arquitetura e decisões de design estão
no [README na raiz do projeto](../README.md).

## Comandos

```bash
npm install       # instala dependências
npm run dev       # servidor de desenvolvimento (http://localhost:5173)
npm test          # testes unitários (Vitest + Testing Library)
npm run build     # type-check + build de produção
```
